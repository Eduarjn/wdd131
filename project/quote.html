What happens with this

This is a course project, so the form does not reach a real integrator. It posts to a confirmation page that shows you exactly what a carrier would receive, which is the useful part anyway: if you can answer these eight questions, you are ready to negotiate.

Nothing is sent to a server and nothing is stored beyond your own browser. The only thing kept is a count of how many requests you have built, so the confirmation page can tell you.
